032620527周坤的STM32F103C8T6 培训作业


环境如下
主控：STM32F103C8T6 最小系统板
工具：STM32CubeMX 6.18.1 + Keil MDK（AC6），ST-Link 烧录
外设：面包板 LED + 1kΩ 电阻、轻触按键


任务完成情况
任务一：500ms 闪烁，可用HAL_Delay                                                     方法：翻转 PA5                                            第一次作业
任务二：500ms 闪烁，禁用HAL_Delay                                                     方法：__NOP 空循环计数延时                     第二次作业
任务三：EXTI 中断控制 LED + 20ms 消抖                                                  方法：PA1 下降沿中断 + 查表消抖              第三次作业
任务五：长按闪烁，短按常亮/常灭，未实现闪烁中的短按回应                 方法：电平偏移计时消抖和判断长短按         第四次作业


声明：
所有的引脚和功能的对应都已在uvprojx文件中已注释的形式写好，但是再次声明：
PC13：板载LED
PC5：面包板上的LED
PC1：按钮
其中第一次第二次作业中引脚被命名，认为不妥，后面多次作业中不再采纳，只以注释形式在程序main.c中呈现




说明：
第一次作业：好像没什么好说的。奇怪，我怎么定义了一个没啥用的PA1？
第二次作业：原来NOP前面是两个下划线。__NOP()中的数字是我掐表计时试出来的
第三次作业：用gettick来获取当下时间，记录为按下按钮时间后与上一次按下按钮的时间比较，小于等于20ms 将直接return。由于板载LED低电平点亮所以我把面包板LED的正极接到了3V3上，两个引脚都是推挽。

硬件接线：
PA5 → 1kΩ → LED → 3.3V（低电平点亮）
PA1 → 按键 → GND（内部上拉）
